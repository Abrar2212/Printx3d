Live 3D preview for custom name keychains: customers type a name, pick a font and colours, and see the 3D print.

== Description ==

Add the `[printx3d]` shortcode to any page to show the 3D studio. Manage colours, products,
currency and the starting text under PrintX3D in the admin menu.

With WooCommerce (free) active, customers add their design to the cart. The price is set on the
server from your product settings; text, font and colours are checked before anything is added.
Each order line keeps the design, and shop staff get a "Download STL" button on the order screen.
Administrators and Shop Managers can edit colours and products.

== Installation ==

1. Upload the plugin zip under Plugins → Add New Plugin → Upload Plugin, then activate it.
2. Open PrintX3D in the admin menu to set colours, products and currency.
3. Put `[printx3d]` on a page.
